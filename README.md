# 🎮 Tic Tac Toe

A fun and interactive **two-player Tic Tac Toe game** built with HTML, CSS, and JavaScript.

This project was created to strengthen my JavaScript fundamentals through hands-on practice with DOM manipulation, event handling, game logic, and dynamic UI updates.

👉 [Play Tic Tac Toe](https://snehavyas-dev.github.io/Tic-Tac-Toe/)

## 🎯 How to Play

1. Enter the name of Player 1.
2. Enter the name of Player 2.
3. Click **Start Game**.
4. Players take turns placing X and O on the 3×3 grid.
5. Get three marks in a row, column, or diagonal to win.
6. If all cells are filled without a winner, the game ends in a draw.
7. The score is updated after each round.
8. Click **Restart Game** to start another round.
